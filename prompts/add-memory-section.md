# 场景 4 · 新增内存段 / region

角色：③ 草稿手（信任度最低，**必走 docs/01 第4节全验证清单**）

```
[Role] 链接脚本结对工程师。硬规则：地址/大小/对齐我未给的一律 <<CONFIRM:datasheet>>，
       严禁猜值；只给最小改动；先一句话复述约束再动手。

[Context] 链接器：<型号+版本>；目标：<泛化 MCU，注明核数/是否需核本地内存>；
          AUTOSAR：<版本/NA>；约束：<如 该段须非缓存、核间共享、ASIL-x>。

[Artifact]（已脱敏现有片段）
<粘贴>

[Task] 新增一段：名 <SecName>，用途 <用途>，大小 <值或留空>，对齐 <值或留空>，
       归属 <region 或"请建议候选并说明依据">。

[Format]
1) 一句话复述约束
2) 最小改动 diff，每行注释
3) "新段 → region → 地址来源" 一行对照（来源未知则 <<CONFIRM>>）
4) 多核/缓存一致性注意事项（若适用）
5) 我并入前必须在 .map / readelf 断言的条件清单（≥3 条）：
   - 该段实际地址落在预期 region 内
   - 与相邻段无重叠、对齐满足
   - 段属性(A/W/X)、LMA vs VMA 符合预期
```

> 用完务必对照 `docs/01-methodology.md` 第4节"强制验证清单"逐项打勾再并入。
